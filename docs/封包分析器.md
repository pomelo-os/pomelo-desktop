# 封包分析器（pomelo-packets）

類似 Wireshark 的封包擷取與分析，含 RTP 串流分析與 VoIP 品質、SIP 呼叫流程圖。全部自己實作（pcap／pcapng 讀寫、協定解析、顯示過濾、BPF 編譯器），沒有使用 libpcap、Wireshark 的程式碼或任何新相依。

> **擷取並重組通訊內容等於監聽通訊。各國與地區對於擷取他人通訊有嚴格規範，未經授權可能違法。請只在你自己有權管理或已取得授權的網路與設備上使用，建議在公司或組織內取得書面授權。**

## 法律與隱私護欄

1. 第一次使用要閱讀「使用須知」並勾選同意才能開始擷取（記在設定；改版會重問）。
2. 預設只做統計（RTP 抖動、遺失、延遲、MOS 估計、串流清單、SIP 流程圖）。播放、匯出 WAV、匯出原始負載、還原影像都要在**該工作階段**另外勾選「我已取得授權」並確認（開新檔案就重設）；命令列要加 `--i-have-authorization`，否則拒絕（結束碼 3）。播放與匯出寫入本機稽核紀錄（時間、動作、串流、檔名；**不含內容**；`~/.local/share/pomelo/packets/audit.log`，權限 0600，設定頁可查看與清除）；匯出的 WAV 帶來源與時間中繼資料。
3. 不自動儲存或上傳封包：擷取要明確按開始；暫存只在記憶體；結束時詢問是否儲存；存檔權限 0600；`pk_encrypt_file` 可用 gpg 對稱加密（需要 gpg）；設定頁一鍵清除。
4. 不破解：SRTP 只做統計；TLS 只辨識記錄層與握手（版本、SNI、密碼套件、憑證 CN），**沒有實作 NSS key log 解密**。
5. 去識別化（可選）：畫面、複製與匯出遮蔽 IP 末段、MAC 後半、SIP 帳號與電話號碼中間數字、主機名稱；命令列 `--anonymize`。
6. 擷取範圍：交換式網路預設只看到進出本機的流量與廣播／多播；整段網路需要鏡像埠或混雜模式。沒有權限時不能擷取，但可開啟 pcap 檔做分析。

## 使用

```
pomelo-packets [檔案]                                開啟視窗（pcap／pcapng／.gz）
pomelo-packets 檔案 --summary [--filter 表達式] [--json]
pomelo-packets 檔案 --conversations | --endpoints | --rtp-streams | --voip-calls [--json]
pomelo-packets 檔案 --follow tcp:N [--hex]           追蹤串流（N 是 --conversations 的編號）
pomelo-packets 檔案 --dump N                         第 N 個封包的逐層欄位
pomelo-packets 檔案 --export-rtp 串流ID --out 檔 --i-have-authorization [--format wav|payload|h264|ivf] [--mix stereo|both|a]
pomelo-packets --capture 網卡 [-f BPF] [-c 數量] [-w 輸出.pcap] [-s 快照長度] [--promisc] [--seconds N]
pomelo-packets --prepare …                           見 patches/README.md 的契約
```
結束碼：0 成功、1 用法錯誤、2 檔案或擷取錯誤、3 沒有授權或權限、4 擷取失敗、5 參數不合法。

擷取需要 `CAP_NET_RAW`：預設經 pkexec（polkit 政策 `tw.fedora.pomelo.packets`）執行 `/usr/libexec/pomelo/pomelo-packets-helper`；管理員也可以改 `setcap cap_net_raw+ep /usr/libexec/pomelo/pomelo-packets-helper`。輔助程式不是 setuid，只有 `list-ifaces`、`check`、`capture` 三個子命令，不執行外部指令，參數嚴格驗證，過濾運算式由它自己編譯成 cBPF，開好 socket 與 TPACKET_V3 環形緩衝後降權並清空 capability（測試驗證 CapEff＝0、NoNewPrivs＝1）。

| 項目 | 狀態 | 說明 |
|---|---|---|
| 擷取：網卡清單、混雜、BPF、數量／秒數限制、snaplen、環形緩衝、丟包統計、奈秒時間戳、TPACKET_V3 | ✔ | 位元組／數量限制在輔助程式與命令列；圖形介面沒有開放「擷取限制」 |

| 協定：Ethernet、VLAN（雙層）、ARP、IPv4／IPv6（含擴充標頭）、ICMP／ICMPv6、TCP（選項、時間戳、視窗縮放）、UDP、DNS、DHCP、HTTP/1.x、TLS（記錄層與握手、SNI、密碼套件、憑證 CN）、SIP、SDP、RTP、RTCP、NTP、SNMP、mDNS、LLMNR、SSDP、NBNS、LLDP、CDP、STP、QUIC（Initial 類型與版本）、WireGuard 識別、MQTT、Syslog、ESP／AH（標頭）、GRE／VXLAN／IPIP | △ | DHCPv6 只認得訊息類型；SNMP 只讀版本與 PDU 類型；TLS 不解密；HTTP 不做 chunked 重組；SACK 區塊不展開 |
| 顯示過濾（欄位比較、contains、matches（萬用字元，無 ReDoS）、in、and/or/not、括號、協定存在）、即時驗證與錯誤位置、自動完成、歷史 | △ | 儲存常用過濾沒做；約 70 個欄位；沒有 `frame.number` 與專家欄位 |
| 封包列表（虛擬捲動、顏色規則、排序、書籤、註解、時間參考點）、詳情樹與十六進位高亮、複製（摘要／十六進位／欄位／JSON） | △ | 顏色規則只能開關（不能改色）；沒有搜尋框與「加為欄」 |
| 追蹤 TCP／UDP 串流、TCP 重組（重傳、亂序、重疊、缺口） | ✔ | 追蹤 HTTP 對話沒有獨立視圖（用 TCP 串流看） |
| 專家資訊、對話表、端點表、協定階層、封包長度、I/O 圖 | △ | 沒有 TCP 時序圖；RTT 只有 SYN→SYN/ACK 估計；對話表沒有 Ethernet 層 |
| RTP：SIP／SDP 登記與啟發式辨識、遺失／亂序／重複／抖動／delta／MOS 估計與燈號、RTCP 對照、問題時段、序號連續性圖、SIP 流程圖與每則訊息內容、呼叫狀態、問題建議 | ✔ | RFC 4571（RTP over TCP）沒做；RTCP-mux 可辨識；同埠多串流依 SSRC 分流 |

## 測試（`make test`；容器內另有 lab 腳本）
- `test/test-packets.c`：pcap／pcapng 往返與畸形檔、協定欄位、顯示過濾（正反向、錯誤與惡意輸入、ReDoS）、BPF 編譯與直譯（與顯示過濾逐封包比對）、TCP 重組與專家資訊、RTP 統計與還原（授權護欄、WAV 對原始正弦波 SNR、DTMF 序列與時間）、去識別化、稽核紀錄、`--prepare` 參數驗證；模糊測試 pcap 1.2 萬、pcapng 1.2 萬、協定解析器（SIP／SDP／RTP／DNS／TLS／HTTP…）6 萬筆；以 ASan＋UBSan 編譯也要通過。
- `test/lab/synth.py`：合成 SIP 呼叫與雙向 RTP（G.711 正弦波、DTMF、遺失、亂序、重複、抖動、SSRC 變化、CN、NAT、忙線／取消／拒絕／無應答／進行中），輸出 `expect.json`（用獨立公式算的預期統計）；`test/check-rtp.py` 比對。
- `test/lab/capture-test.sh`：容器內（NET_RAW、NET_ADMIN，不用 --privileged）用 veth 對驗證擷取、過濾、限制、snaplen、VLAN、降權、拒絕惡意參數、吞吐量。
- `test/lab/tshark-test.sh`、`cross-check.py`：容器內安裝 tshark／tcpdump（只當對照，不是專案相依，不隨附）逐欄交叉驗證與讀寫往返。
- `test/prepare-test.py`：`--prepare` 與對網路探索的呼叫（假的 pomelo-netscan）。
- 截圖用 `test/shot.sh`（Xvfb），畫面存在 `shots/`。
