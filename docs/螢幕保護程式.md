# 螢幕保護程式（pomelo-screensaver）

## 閒置時間表
```
閒置 N1 分鐘：螢幕保護程式   （saver.after，預設 5）
閒置 N2 分鐘：鎖定螢幕       （power.lock_after，預設 10）
閒置 N3 分鐘：關閉螢幕       （power.screen_off_after，預設 15）
閒置 N4 分鐘：休眠           （power.suspend_after／_battery）
```
- 保護程式只在 N1 比 N2、N3、N4 都早時才會出現（`saver-idle.h` 的 `sv_idle_saver_runs`；pomelo-power、系統設定兩頁、單元測試共用）。
- 保護程式正在跑、鎖定時間到：pomelo-power 送 SIGUSR1，保護程式先啟動 pomelo-lock、等 `_POMELO_LOCKED` 出現（鎖定畫面蓋好）才結束，桌面不會閃現。
- 關螢幕、休眠：pomelo-power 送 SIGTERM，保護程式直接結束。
- 喚醒時要求密碼：「依鎖定時間」（預設，什麼都不多做）、「一律要」（喚醒時先交給鎖定畫面）、「不用」。`--lock-now`＝一律要。
- 保護程式是 overlay 層蓋住畫面（尚未鎖定）：萬一它當掉，會先去啟動鎖定（需要密碼時）。通知被蓋在下面（隱私，與鎖定一致）。

## 設定鍵
`saver.enable`、`saver.after`、`saver.kind`（clock／photos／pet／flow／stars／bubbles／text／black／random）、`saver.random_set`、
`saver.require_password`（0 不用、1 一律、2 依鎖定）、`saver.skip_on_battery`（0 照常、1 不啟動、2 純黑）、`saver.skip_when_playing`、`saver.jitter`（像素）、
`saver.power_save`（10 fps）、`saver.clock.24h／seconds／color／lunar`、`saver.photos.dirs／interval／random／names`、`saver.text`、`saver.text.float`。

見回報；影格率：時鐘 1～2、文字 2、小柚 5～12、照片 12、流動色彩 15、星空 15、氣泡 20、純黑 0（畫一次）；省電模式上限 10。
